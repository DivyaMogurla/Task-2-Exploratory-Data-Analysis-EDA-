# Retail Revenue Intelligence: EDA & Business Insights Using Python

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a retail dataset to identify trends, patterns, relationships, outliers, and business insights.

## Objectives

- Understand the structure and quality of the dataset
- Analyze revenue and customer segments
- Study product category performance
- Identify relationships between numerical variables
- Detect outliers and anomalies
- Generate meaningful business insights

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## EDA Analysis

- Data Quality Check
- Statistical Analysis
- Trend and Pattern Analysis
- Correlation Analysis
- Outlier Detection
- Customer Segment Analysis
- Product Category Analysis
- Business Insights and Recommendations

## Visualizations

- Correlation Heatmap
- Quantity vs Revenue Scatter Plot
- Revenue Outlier Box Plot
- Customer Segment Revenue Chart
- Revenue by Product Category and Customer Segment
